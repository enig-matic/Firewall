# Simple Firewall Simulator 🛡️

A simple Python project that simulates basic firewall rules.

## Features
- Generates random IP addresses.
- Checks IP addresses against firewall rules.
- Blocks specific IP addresses.
- Allows other IP addresses.
- Generates a random number for each IP.

## Requirements
- Python 3

## How to Run

```bash
python3 firewall.py
```

## Example Output

```text
IP: 192.168.1.3, Action: block, Random Number: 1234
IP: 192.168.1.12, Action: allow, Random Number: 5678
```

*Note: The IP addresses and random numbers will change each time you run the program.*

## Purpose

This project is made for learning basic Python programming and firewall rule logic.

**Disclaimer:** This is only a simulation. It does not block real network traffic.
